# Paid Access 0.1.0-beta.1

The first public npm beta is available. The EmDash plugin directory remains
unpublished. Try the [protected demo](https://masonjames.com/blog/paid-access-demo/):
existing Stripe memberships unlock the page, and agents can buy its Markdown
with Base Sepolia test USDC.

Paid Access brings Stripe memberships for people and origin x402 paid reads for
AI agents to EmDash. Use either module or both, with entry and taxonomy rules,
server-rendered paywalls, and payment receipts in the admin. Both modules start
off on a fresh installation.

The complete plugin is free under **GPL-2.0-or-later**. There are no license keys,
paid feature tiers, or transaction percentages. Payments go to the publisher's
Stripe account or wallet; provider fees may apply. Setup, migration, hosting,
and ongoing support are separate [services from Mason James](https://masonjames.com/plugins/paid-access/).

## Install

Use a server-rendered EmDash 1.2 site on Node 22.12+ with Astro
`^6.1.3 || ^7.3.5`:

```sh
pnpm add emdash-paid-access@0.1.0-beta.1 @emdash-cms/x402@1.2.0
```

Register the core descriptor and `paidAccessAstro`, then render protected bodies
through `PaidContent`. See the [installation guide](../guides/installation.md)
for the configuration and source-build option.
The npm package supplies both pieces; an EmDash directory listing is not required.

## Beta scope

- Stripe Checkout, member sign-in, billing portal, and configured plan entitlements.
- Origin x402 paid Markdown reads; testnet and mainnet receipts are separated.
- Optional delegation while Restrict With Stripe remains installed.
- No Gateway verification, subscriber agent tokens, passes, free-member
  entitlements, automatic migration, or checkout trial configuration.
- Node is the initial host target. Cloudflare/Workers and a registry-installed
  core plus companion require separate verification.
- With the companion enabled, HTML responses use `Cache-Control: private,
  no-store`, including public pages. This beta disables shared HTML caching;
  configure your proxy/CDN accordingly and allow for the extra origin traffic.

Site owners must verify feeds, APIs, alternate routes, and caching as well as
the post template. Begin payment testing on Base Sepolia and in Stripe test mode.
See the [hosting checklist](../guides/hosting-and-caching.md) and
[versioned verification report](0.1.0-beta.1.md) for the evidence and its limits.
