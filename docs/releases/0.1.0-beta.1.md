# 0.1.0-beta.1 verification

Source beta prepared October 9, 2026. npm and EmDash directory publication remain
pending. Source publication, local validation, and deployed-host acceptance are
separate milestones.

## Verified locally

- Node 22.23.3, pnpm 12.10.1, EmDash/x402 1.2.0 and Astro 7.3.5.
- Dependency peer check: no issues. Typecheck and build passed.
- 188 unit/component/route tests passed; the opt-in live settlement test was skipped.
- Four tests passed through the real EmDash/workerd sandbox, including private
  route permissions, CSRF, settings after restart, and network-filtered receipts.
- Manifest validation, sandbox bundling, packed consumer imports, corresponding
  source preservation, and exact sandbox/npm backend parity passed.
- Independent read-only review: Codex gpt-6.1-sol, high effort. No blocker found in
  the build-tool compatibility patch, public guides, or source preservation.
- Secret-pattern scans found no matches in the reviewed history or proposed text
  files. Internal operational planning is not part of the public source release.

The build-tool patch changes deprecated tsdown option names to their equivalent
supported names. Dependency peer checks do not suppress upstream deprecation
notices. See [dependency compatibility](../guides/testing-and-releases.md#dependency-compatibility).

The package import check uses extracted files and locally installed peers. It
is not evidence of a settled payment or a deployed registry-core/companion pair.
Public documentation links/snippets were checked separately.

## Consumer and source checks

The public source candidate is commit `fadbd2f41fac21e167159e0ce200dd581e960cdb`.
Its [GitHub release-check run](https://github.com/masonjames/emdash-paid-access/actions/runs/37973499841)
passed. The npm archive was extracted outside Git and passed a frozen offline
install, typecheck, build, and all 186 default tests using its preserved source.

A separate blank EmDash 1.2/Astro 7.3.5 consumer installed the archive and passed
its build and peer checks. A real Base Sepolia transaction settled 0.001 test
USDC and returned the protected Markdown with a payment-response header. The
receipt remained in SQLite after a server restart. Unpaid GET and HEAD requests
returned 402 without the protected body, including after the paid request.

Stripe CLI created isolated test products matching the two legacy plan choices
and an active synthetic test subscription. The real server-rendered paywall
allowed that member and denied an anonymous visitor and a member without a
subscription. No live billing was changed and no email was sent; test sessions
were seeded directly for the entitlement check.

This check found that setting headers inside a child Astro component did not
protect streamed HTML. The response middleware now sets private/no-store for
HTML, including public pages. The rebuilt consumer passed both allowed and
denied checks with the correct response headers; two regression tests cover the
streaming boundary and preservation of non-HTML cache policy. Runtime fix:
`0930c9ff118a87a8dfe0a9810063264ea3df2a76`, with a passing
[release-check run](https://github.com/masonjames/emdash-paid-access/actions/runs/37991913443).

The integration site's candidate passed its full Dagger gate and container build,
including its existing legacy member-authentication regressions. Its current source is `c58f0aca37d1b41221877cfe65a6e7bf0e9ce42e`.
Database-copy rehearsals preserve existing records and prove previous-image
compatibility. Public deployed-host acceptance remains separate.
