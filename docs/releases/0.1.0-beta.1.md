# 0.1.0-beta.1 verification

Release date: October 9, 2026. The npm beta and matching sandbox archive use the
same source revision. The EmDash plugin directory remains unpublished.

## Local and consumer checks

- Node 22.23.3, pnpm 12.10.1, EmDash/x402 1.2.0 and Astro 7.3.5.
- Peer compatibility, TypeScript, build, manifest validation and package checks passed.
- 188 unit/component/route tests and four real EmDash/workerd sandbox tests passed.
  The sandbox checks include private permissions, CSRF, settings after restart,
  and network-filtered receipts. The default suite skips the opt-in settlement test;
  real settlement was verified separately against deployed hosts.
- npm and sandbox backend bytes match. The npm package preserves editable source,
  tests, build configuration, patches and exact original manifest/lockfile copies.
- A blank EmDash/Astro consumer installed the archive and built successfully.
  Its Stripe test member was allowed; anonymous and unsubscribed readers were denied.
  A Base Sepolia purchase returned the protected body and its receipt survived restart.
- The integration site's full Dagger gate and container build passed, including
  existing member-authentication regressions. Database-copy rehearsals preserved
  existing records and verified previous-image compatibility.

The consumer test exposed an Astro streaming issue: headers set by the child
component did not reach the response. Middleware now applies private/no-store to
all HTML, including public pages. Two regression tests cover streamed HTML and
unchanged non-HTML caching. Runtime fix: `0930c9ff118a87a8dfe0a9810063264ea3df2a76`,
with a passing [release check](https://github.com/masonjames/emdash-paid-access/actions/runs/37991913443).
Later release edits update documentation and package metadata.

## Deployed acceptance

The reviewed site source `c58f0aca37d1b41221877cfe65a6e7bf0e9ce42e` passed staging
and was deployed to [masonjames.com](https://masonjames.com/blog/paid-access-demo/).
Both deployments retained rollback checkpoints before changing the running image.

The production test settled 0.001 Base Sepolia test USDC in
[transaction 0x8ff2…3b12](https://sepolia.basescan.org/tx/0x8ff2a188f26b737bdec7a622f63f315dc39ec1ddcff6a1896d75813e31803b12).
The buyer and receiver were the same test wallet; this proves settlement and
content delivery, not revenue or mainnet readiness. Production Stripe credentials,
existing customers and Ghost plan mappings were preserved.

Production observation passed: 25 checks over 604.9 seconds, with the same
healthy task, unchanged configuration, no runtime error markers, no pending or
unknown migrations, and the settled receipt still present.
The owner approved this bounded observation for the public beta. Seven days of
production observation have not been completed.

## Limits of this evidence

Stripe entitlements used a real test subscription and seeded reader sessions.
Checkout creation was verified; browser card entry, email delivery and the full
email-link round trip were not exercised in this release window. No live Stripe
customer was charged and no membership email was sent. Production's human access
continues to delegate to the existing Restrict With Stripe installation.

A deployed registry core with its npm companion, Cloudflare/Workers hosting,
mainnet payments and editor interaction require separate host acceptance.
Nine upstream transitive deprecation notices remain; there are no dependency
peer conflicts. See [dependency compatibility](../guides/testing-and-releases.md#dependency-compatibility).

## Matching artifacts

Use the npm and sandbox archives attached to the
[v0.1.0-beta.1 source release](https://github.com/masonjames/emdash-paid-access/releases/tag/v0.1.0-beta.1),
with their SHA-256 sidecars. Those sidecars identify the actual published bytes;
rebuilding the same source can change archive timestamps and therefore digests.
The npm artifact is published with the `beta` tag, not promoted to `latest`.
